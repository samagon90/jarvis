# 🔧 Jarvis Мастер — умный помощник для ремонтной мастерской

Мобильное приложение для Android на **Kotlin + Jetpack Compose** для учёта ремонтов,
финансов и запчастей в мастерской по ремонту телефонов.

---

## ✨ Возможности

### 📱 Учёт ремонтов
- Создание заказ-нарядов: устройство, серийный номер/IMEI, неисправность, диагноз.
- Статусы жизненного цикла: *Принят → Диагностирован → В работе → Ждёт запчасть → Готов → Выдан / Отменён*.
- Кнопка **«Выдать клиенту»** — автоматически создаёт транзакцию дохода.
- Привязка клиента к заказу, история ремонтов клиента.
- Поиск по устройству / IMEI / неисправности + фильтр по статусам.

### 💰 Финансы
- Доходы и расходы, прибыль за месяц.
- Учёт долгов клиентов (частичная оплата) — сумма долга видна на главном экране.
- Простой график «доход по дням» и список операций.
- Добавление расходов (запчасти, аренда, реклама и т.п.).

### 🔩 Склад запчастей
- Справочник запчастей: категория, артикул/штрих-код, остаток, минимальный остаток, закупка/продажа, место на складе.
- **Автоматическое списание запчастей** в заказ (уменьшение остатка + себестоимость).
- **Алерты о заканчивающихся запчастях** (остаток ≤ минимума) на главном экране и в разделе запчастей.
- Экспорт справочника в **CSV**.

### 👤 Клиенты
- База клиентов: имя, телефон, Telegram, примечания.
- Карточка клиента со всей историей его ремонтов.

### 📊 Главный экран (дашборд)
- Доход / прибыль за неделю, выручка за сегодня, общий долг.
- Количество заказов в работе, «Готовы к выдаче».
- **Напоминания**: заказы, готовые, но не выданные; заканчивающиеся запчасти.

### ⚙️ Настройки и данные
- Название мастерской, телефон, адрес, срок гарантии.
- Светлая / тёмная / системная тема.
- **Экспорт резервной копии** всех данных в JSON (через системное «Поделиться»).

## 🚀 Как запустить

1. **Откройте проект в Android Studio** (Hedgehog или новее).
   - Это самый простой путь: Android Studio сам скачает Gradle 8.9 и соберёт проект.
2. Если понадобится пересоздать **Gradle Wrapper** (при работе из терминала):
   ```bash
   gradle wrapper --gradle-version 8.9
   ```
3. Дождитесь синхронизации Gradle, выберите устройство/эмулятор и нажмите **Run ▶**.

> При первом запуске на реальном устройстве приложение создаст пустую базу — данные
> добавляйте через интерфейс. Резервную копию можно сделать в **Настройки → Экспорт**.

## 📁 Структура проекта

```
app/src/main/java/com/jarvis/master/
├── data/                    # Репозиторий и бизнес-логика
│   ├── db/                  # Room: сущности и DAO
│   └── settings/            # DataStore (настройки мастерской)
├── ui/
│   ├── screens/             # Экраны Compose
│   ├── components/          # Переиспользуемые UI-компоненты
│   ├── theme/               # Тема (цвета, типы)
│   └── *ViewModel.kt        # ViewModel-ы
└── util/                    # Форматирование, экспорт
```
