# ☁️ Настройка облачной базы (Supabase) — пошагово

Supabase — бесплатный облачный сервис (PostgreSQL). Здесь хранится ваша база,
к которой подключаются **оба телефона** (ваш и второго человека), а также фото.

> Время: ~10 минут. Нужна только электронная почта. **Никакой банковской карты не требуется.**

---

## Шаг 1. Создать аккаунт и проект

1. Откройте **https://supabase.com**
2. Нажмите **Start your project** → зарегистрируйтесь (Sign up) по email + паролю.
   Подтвердите письмо.
3. В панели нажмите **New project**.
4. Заполните:
   - **Name**: например `jarvis-master`
   - **Database Password**: придумайте и **сохраните его** (нужен только Supabase, вам — не обязательно, но запишите)
   - **Region**: выберите ближайший (например `Frankfurt (eu-central-1)` — Европа)
5. Нажмите **Create new project** и подождите **1–2 минуты**, пока создаётся база.

## Шаг 2. Создать таблицы

1. В левом меню выберите **SQL Editor**.
2. Нажмите **New query**.
3. Откройте в этом репозитории файл **`supabase/schema.sql`** и скопируйте весь текст.
4. Вставьте текст в редактор и нажмите **Run** (или Ctrl+Enter).
5. Внизу должно появиться зелёное `Success. No rows returned` (или список созданных таблиц).

> Готово — в разделе **Table Editor** слева появятся таблицы:
> `clients`, `repairs`, `repair_photos`, `parts`, `repair_parts`, `transactions`.

## Шаг 3. Создать хранилище для фото

1. В левом меню выберите **Storage**.
2. Нажмите **New bucket**:
   - **Name**: `repair-photos`
   - Включите переключатель **Public bucket**
   - **Create bucket**
3. (опционально) Откройте бакет → вкладка **Policies** → проверьте, что стоит разрешение на чтение/запись для anon.

## Шаг 4. Найти URL проекта и anon-ключ

1. В левом меню откройте **⚙️ Project Settings** (иконка шестерёнки) → **API**.
2. Скопируйте:
   - **Project URL** — строка вида `https://abcdefgh.supabase.co`
   - **Project API keys → anon public** — длинная строка, начинается с `eyJ...`
3. ⚠️ **Никому не давайте** ключ **`service_role`** — он секретный, только для вас.

## Шаг 5. Прислать мне ключи (или вписать в приложение)

Пришлите мне два значения (их можно безопасно вставлять в приложение,
anon-ключ — публичный по задумке Supabase):

```
Project URL: https://xxxx.supabase.co
anon key:   eyJhbGciOi...
```

Как только пришлёте — я подключу базу, синхронизацию и фото в приложении.

---

## Что дальше (что я сделаю в коде после получения ключей)

1. Подниму минимальную версию Android до **8.0 (API 26)** — уже сделано.
2. Добавлю библиотеку Supabase и поле ввода URL/anon-ключа в настройках.
3. Переведу данные (клиенты, ремонты, запчасти, финансы) в облачную базу —
   **оба телефона будут видеть одну и ту же информацию**.
4. Добавлю **прикрепление фото** к ремонту с камеры/галереи с загрузкой в
   хранилище `repair-photos`.

## Полезные ссылки
- Таблицы и данные: **Table Editor**
- Живая синхронизация (опция, чтобы изменения появлялись почти мгновенно): **Database → Replication → Enable Realtime** на нужных таблицах (начинать можно без этого).
- Бесплатный тариф Supabase: 500 МБ БД, 1 ГБ хранилища — мастерской такого размера хватит с запасом.
